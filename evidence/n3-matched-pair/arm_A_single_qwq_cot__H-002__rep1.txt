### Python Function `count_non_adjacent(n)`
This brute-force function generates all permutations of \(n\) books labeled 'A', 'B', ..., and counts those where A and B are not adjacent.

```python
from itertools import permutations

def count_non_adjacent(n):
    books = [chr(ord('A') + i) for i in range(n)]
    count = 0
    for p in permutations(books):
        adjacent = False
        for i in range(len(p) - 1):
            if (p[i] == 'A' and p[i+1] == 'B') or (p[i] == 'B' and p[i+1] == 'A'):
                adjacent = True
                break
        if not adjacent:
            count += 1
    return count

# Verify for n=5:
```
